# Changelog — Flex Fit Active Wear

## Part 3 completion update

### Website structure and content
- Rebuilt the malformed HTML pages into valid, semantic HTML5 documents.
- Standardised page titles, navigation, header, footer and page structure across all six pages.
- Corrected navigation destinations and renamed the original `contact .html` page to `contact.html`.
- Preserved the supplied Flex Fit brand story, product photographs, video, social media handle and contact number.
- Retained product names and listed prices from the supplied product page.

### Design and accessibility
- Applied the proposal's neutral, soft blue, peach, black and white colour palette.
- Standardised Calibri typography, spacing, cards, buttons and responsive layouts.
- Added mobile navigation, keyboard focus styles, skip link and reduced-motion support.
- Added meaningful alternative text and descriptive image filenames.

### JavaScript and forms
- Replaced the broken JavaScript with a single deferred script that runs after the document is ready.
- Added responsive menu interaction, active navigation state and dynamic footer year.
- Added asynchronous product catalogue loading from a local JSON file using the Fetch API (AJAX-style), live product search, FAQ accordion and gallery lightbox.
- Added client-side validation and user feedback to enquiry and contact forms.
- Added WhatsApp enquiry message preparation and email-draft preparation for contact messages.

### SEO and deployment
- Added page-specific titles, descriptions and relevant keywords.
- Added `robots.txt`, `sitemap.xml` and Netlify static-site configuration.
- Added a deployment URL placeholder that must be replaced with the actual Netlify domain after publishing.

### Documentation
- Added project README, testing notes and references.
- Preserved the supplied proposal and ICE task PDFs in the `Documents` folder for supporting context.
